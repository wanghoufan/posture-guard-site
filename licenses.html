开源许可

坐姿守护 PostureGuard 使用成熟的开源组件完成相机取景、姿态识别与本地数据存储；所有画面分析都在手机本地完成，不联网、不上传。以下列出组件用途与对应许可证全文。

组件与用途

共 188 个第三方组件，下表为主要组件；完整清单见文末。

  • MediaPipe Tasks Vision 0.10.14Apache-2.0

    在本机运行姿态与人脸关键点模型，不联网

  • MediaPipe Pose Landmarker (Lite / Full)Apache-2.0

    识别人体耳、肩、髋等关键点的模型文件

  • MediaPipe Face LandmarkerApache-2.0

    判断头部朝向、辅助区分低头与前伸的模型文件

  • AndroidX (CameraX, Compose, Room, Lifecycle, Navigation, DataStore)Apache-2.0

    相机取景、界面组件、本地数据库与设置存储

  • Kotlin standard library, kotlinx.coroutinesApache-2.0

    开发语言标准库与后台任务调度

  • Guava, Protocol Buffers, Okio (transitive)Apache-2.0 / BSD-3-Clause

    上述组件内部使用的传递依赖

  • Checker Framework annotationsMIT

    编译期空类型注解，不参与运行时逻辑

  • desugar_jdk_libs 2.1.5GPL-2.0 + Classpath Exception

    让低版本 Android 也能使用 java.time 等标准 API
